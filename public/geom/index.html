The GEOM axis, glyph by glyph

Cal Sans redraws 16 letters as one axis moves. This is every one of them, the value each swap fires at, and the static cv/ss feature that reaches the same form when you cannot move an axis.

The presets below are parked positions, not the product. ReCal exists so you can put GEOM wherever you want, move the switching points yourself, and download a static font with your decisions baked in.
